# Release notes

## Ruang Uji 1.0.0 — 2026-10-26

First independent, framework-free static website release.

- Added reusable catalogue, search/status filter, Practice Mode, Test Mode, passages, translations, independently derived keys, evidence and detailed option reviews.
- Added saved drafts and attempts, browser-local backup/export/import merge, versioned IDs, optional stopwatch and retakes.
- Added initial TKA English PDF as 20 questions across five passages. **17 questions gradeable; 4, 5 and 19 ungradable pending source correction or authoritative clarification.**
- Added offline data/source validation, independent scoring regression tests, storage tests and GitHub Actions.
- Added Linux Mint GitHub Desktop/Cloudflare Pages deployment guide and safe future-PDF expansion procedures.
- Baseline/patch target: **1.0.0**. Data and progress schema: **v1**.

### Editorial limitations

No official source key was supplied. Keys and explanations are independently reviewed working answers, not official/exam-board endorsed. The uploaded PDF's publication rights are unknown; confirm permission before any public hosting. Browser visual automation was attempted but blocked by an administrator URL policy; manual device acceptance checks are outstanding.
